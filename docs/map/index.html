The worldOne map, several questions

Pick a series. Every country the publisher covers is coloured, not only the ones this directory writes about — the gap between those two sets is itself worth looking at. A hatched country is one the series does not carry.

Equal Earth projection: a square kilometre takes the same ink anywhere on it. Antarctica is cropped. Country outlines are Natural Earth, public domain; the series are the World Bank's, CC BY 4.0, each fetched on the date its data page names.
